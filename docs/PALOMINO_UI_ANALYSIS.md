# Palomino → NAYAN visual analysis

Reference pages inspected on 2026-09-30: https://palominoprod.com/en/contact, https://palominoprod.com/en, https://palominoprod.com/en/work, https://palominoprod.com/en/about.

Contact and home were inspected visually in the cloud browser; work and about were inspected through retrieved page content. The browser viewport was approximately 1363×936. Exact 1440/1920 reference captures have not been obtained; do not describe this as a pixel-identical clone.

## Observed language

- Contact uses a nearly black surface, very large white uppercase neutral sans typography, tight title tracking, quiet grey metadata and sparse rectangular fields.
- Navigation exposes repeated text layers in the document, with a single readable label to assistive technology. Adopt a clipped vertical text swap, clear active underline, keyboard focus, and reduced-motion support.
- Home gives film footage the full viewport. Its photography carries colour while chrome stays monochrome. Use existing NAYAN staged CCTV, never borrowed Palomino media or an invented surveillance image.
- Contact is asymmetric: form left, compact contact metadata right. Translate this to dominant evidence/media plus narrow operational detail; avoid six equal rounded cards.
- Footer provides grouped information and an oversized spaced wordmark. Translate it to module links, source/runtime information and NAYAN.

## Translation

Use #080808 ground, #f5f5f0 text, thin #343434 rules, 24–48px fluid gutters, zero corner radii, no gradients/glows. Display type uses system Helvetica/Arial so offline execution does not depend on remote fonts. Operational headings use clamp(44px, 7vw, 112px), while the landing wordmark is much larger. Use tabular numerals for measurements. Keep red/amber/green only for labelled operational states.

Motion: 160ms hover, 280ms state, 650ms page entrance. No bounce, scroll hijacking, custom pointer or decorative looping canvas. Media expansion uses progressive CSS scroll animation where supported, with the full visible static frame as fallback. Native scrolling remains available.

## Boundaries

The supplied redesign supersedes the older graphite/cyan UI direction in ui.md. Preserve provenance, demo labels, independent verification/response states, signal safety constraints and privacy rules. This is a design-language adaptation, not reuse of Palomino's logos, copy, footage or proprietary source.
